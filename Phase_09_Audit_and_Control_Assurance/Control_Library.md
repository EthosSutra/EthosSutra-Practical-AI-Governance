# Executive Summary

Effective AI Governance is built upon well-defined and consistently implemented control activities.

Policies define expectations.

Risk assessments identify exposure.

Monitoring detects operational changes.

Controls ensure that governance requirements are actually enforced.

The AI Control Library serves as the centralized repository of governance controls implemented across GlobalBank Nexus.

Each control defines the objective, implementation approach, ownership, monitoring requirements and evidence necessary to demonstrate operational effectiveness.

The Control Library supports enterprise governance, internal audit, regulatory inspections and continuous assurance by providing a standardized catalogue of preventive, detective, corrective and compensating controls applied throughout the AI lifecycle.

The purpose of this document is to establish a centralized enterprise inventory of governance controls protecting GlobalBank Nexus throughout its lifecycle.

# 13. Enterprise Control Effectiveness Rating

Each governance control shall be evaluated using a standardized effectiveness model.

| Rating | Description | Governance Action |
|---------|-------------|-------------------|
| Effective | Control consistently achieves its intended objective | Continue monitoring |
| Effective with Improvement Opportunities | Minor weaknesses identified | Implement improvement actions |
| Partially Effective | Control operates inconsistently or requires enhancement | Develop remediation plan |
| Ineffective | Control fails to achieve intended objective | Immediate corrective action |
| Not Tested | Control effectiveness has not yet been validated | Schedule testing |

# 18. Enterprise Best Practices

| Best Practice | Business Value |
|--------------|----------------|
| Assign a named owner for every control | Establishes accountability and governance ownership |
| Link every control to one or more enterprise risks | Demonstrates measurable risk reduction |
| Automate controls wherever practical | Improves consistency and reduces manual effort |
| Collect evidence continuously rather than only during audits | Strengthens audit readiness |
| Periodically review control relevance | Ensures controls remain aligned with business and regulatory changes |
| Integrate control performance into executive governance reporting | Supports informed leadership decisions |

---

# 19. Lessons Learned

| Observation | Recommendation |
|------------|----------------|
| Controls without ownership gradually become ineffective | Assign accountable business and technical owners |
| Manual controls are more prone to inconsistency | Automate preventive and detective controls where feasible |
| Testing alone does not improve governance | Ensure remediation actions are implemented and verified |
| Governance frameworks evolve over time | Review and update the Control Library regularly |
| Effective controls require measurable evidence | Standardize evidence collection across all governance domains |
